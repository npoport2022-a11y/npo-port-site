安心して戻れて、
また一歩を踏み出せる場所。

NPO法人PORTは、発達に特性のある子ども・青年とその家族が、好きなことや体験、人とのつながりを通して、自分らしく社会と関わっていける地域づくりを目指しています。

活動を見る 団体概要
PORT

PORTは英語で「港」。安全に戻ることができ、そこから次の場所へ出ていける。そんな場でありたいと考えています。

ABOUT PORT

人を変えるより、
環境と関わり方を変えていく。

子どもや青年の行動だけを見るのではなく、その背景や環境にも目を向けます。安心できる場所、好きなことから始まる関係、できたという実感。その積み重ねを大切にしています。

「PORT」には、いつでも気軽に戻ることができ、そして自分のタイミングで社会へ出ていける場所でありたい、という願いを込めています。

私たちが目指すこと

発達に特性のある人が孤立せず、家庭・教育・福祉・地域がゆるやかにつながりながら、自分らしく生活していける地域社会を目指します。

VALUE 01

やすらぎ → つながり → 達成感

まず安心できること。その上で人とつながり、挑戦や達成につなげます。

VALUE 02

環境を整える

本人だけに変化を求めず、物的・人的な環境や伝え方を調整します。

VALUE 03

「好き」から関係をつくる

興味や得意を入口に、人との関係や新しい体験へ広げていきます。

OUR ACTIVITIES

PORTの主な活動

自然体験、学び、アセスメント。それぞれを独立した活動ではなく、子ども・青年と家族を地域で支えるための入口として位置づけています。

YOKA-KOTO

キッズキャンプ・自然体験

農業体験や自然体験、宿泊キャンプなどを通して、「やってみたい」を大切にしながら、人との関わりや生活経験を広げます。

FAMILY

ファミリーキャンプ

家族で自然の中に出かけ、日常とは少し違う時間を過ごす活動です。保護者同士や子ども同士がゆるやかにつながる場にもなります。

現在の活動案内を見る →
MANABIYA PORT

学び舎PORT

保護者・教育・福祉関係者が学び合うセミナーや、子どもの学び方・困りごとの背景を整理する心理検査などを行っています。

心理検査について見る →
PSYCHOLOGICAL ASSESSMENT

数値だけで終わらない。
困りごとの背景から、支援へ。

WISC-V等の心理検査結果を一つの手がかりとして、お子さんの得意さ・負担になりやすいこと、家庭や学校での様子を合わせて整理します。診断を行うものではありません。

心理検査の詳細を見る
① 認知特性を把握
得意・不得意のバランスを一つの手がかりとして整理します。
② 主訴・行動観察と照合
点数だけではなく、日常の困りごとや検査中の様子も重視します。
③ 家庭・学校での具体策へ
学習方法、環境調整、合理的配慮など、実行可能な支援につなげます。
